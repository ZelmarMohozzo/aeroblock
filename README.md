# Aeroblock

Landing de **Aeroblock — para vientos de playa**: paravientos de 2, 3 y 4 metros, venta mayorista y minorista en Uruguay.

Incluye un simulador para subir el logo de una empresa (hotel, parador, tienda) y ver en el momento cómo queda impreso en el Aeroblock, con la imagen arriba y el texto abajo.

Sitio publicado con GitHub Pages: https://zelmarmohozzo.github.io/aeroblock/
